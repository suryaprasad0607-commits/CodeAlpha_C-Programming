# CodeAlpha_C-Programming
# Basic Calculator Using Switch Statement in C 

## 📌 Project Overview

This project is a simple **Basic Calculator** developed using the C programming language. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division using the `switch` statement.

The program takes two integer inputs from the user and an arithmetic operator to perform the selected operation.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division by zero handling
- Invalid operator detection
- Menu-free, user-friendly input system

## 🛠️ Technologies Used

- **Programming Language:** C
- **Concepts Used:**
  - Variables and Data Types
  - Input and Output Functions (`printf()` and `scanf()`)
  - Switch Statement
  - Conditional Statement (`if-else`)
  - Arithmetic Operators

## ⚙️ How to Run the Program

1. Clone this repository:
   ```bash
   git clone <repository-url>
   ```

2. Open the project folder.

3. Compile the C program:
   ```bash
   gcc calculator.c -o calculator
   ```

4. Run the executable:

   **Windows:**
   ```bash
   .\calculator.exe
   ```

   **Linux / macOS:**
   ```bash
   ./calculator
   ```
